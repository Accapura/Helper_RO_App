История обновлений

Release v0.4.16 актуальная версия
25.09.2026
  • Добавлен глобальный поиск в сайдбаре: один запрос ищет сразу по всем разделам (Устав, УК, ТК, УВС, ДУ, Общее, Полезное, О проекте), совпадения — в выпадающем списке.
  • Клик по результату глобального поиска (или Enter) переключает вкладку и подсвечивает найденный текст там, где это поддерживается.
  • «Избранное»: записи стали кликабельными — клик по статье сразу переключает на нужную вкладку, прокручивает к ней и коротко подсвечивает.
  • Группы навигации («Кодексы», «Уставы», «Личное») теперь сворачиваются и разворачиваются плавной анимацией вместо мгновенного скрытия.
  • Исправлены заголовки в «Общих документах РО»: название документа теперь выделяется заметнее, чем заголовок главы внутри него.
  • Ускорен глобальный поиск: убрана повторная обработка HTML при каждом нажатии клавиши.
Release v0.4.15 25.09.2026
  • Навигация полностью пересобрана: вместо ряда иконок сверху — вертикальная боковая панель слева на всю высоту окна.
  • Разделы сгруппированы: «Кодексы» (УК РО, ТК РО) и «Уставы» (УФСБ, УВС, ДУ) — каждая группа сворачивается отдельно, по умолчанию раскрыты.
  • «Избранное» вынесено из группы «Личное» в отдельный пункт меню.
  • «Общее» переименовано в «Общие документы РО» и оформлено отдельной акцентной карточкой со стрелкой.
  • Окно стало шире (720px вместо 560px), чтобы боковая панель не съедала место у содержимого.
Release v0.4.14 25.09.2026
  • «Общие документы РО»: добавлена Конституция РО (с оглавлением статей и поиском), Процессуальный кодекс РО и Федеральный закон «О вооружённых силах РО».
  • Добавлены две новые вкладки: «УВС» (Устав внутренней службы) и «ДУ» (Дисциплинарный устав) ВС РО.
  • Вкладка «Устав ФСБ» переименована в «УФСБ».
  • У Конституции РО добавлена плавающая кнопка «Оглавление» с быстрым переходом по главам.
  • Добавлена новая тема оформления «Тёмный минимализм» — установлена по умолчанию.
Release v0.4.13
19.09.2026
  • Обновлённый Устав ФСБ.
  • Добавлен новый раздел: Федеральный закон «О государственных территориях РО».
  • Добавлен раздел: «Фото Закрытых территорий».
  • Мелкий фикс: имена авторов на вкладке «О проекте» оформлены акцентным цветом темы вместо обычного белого.
Release v0.4.12
10.09.2026

  • «Правила государственных организаций»: раздел «Общее положение» пересобран под новую нумерацию, ужесточены меры наказания по п. 1.4, 1.6, 1.10.
  • «Устав ФСБ»: добавлен пункт 16.4 — обязанность явиться в строй вне зависимости от времени суток, если его организовывает старшее руководство.
06.09.2026
  • «УК РО» полностью обновлён: актуализированы Общая и Особенная части, изменены составы преступлений, приоритеты розыска и меры наказания по всем статьям.
05.09.2026
  • «Устав ФСБ» обновлён ещё раз: добавлены новые статьи — дресс-код, поведение в строю, правила использования служебной рации, уточнены формулировки по действующим главам.
01.09.2026
  • Первый официальный релиз — все функции, накопленные с v0.3.x по v0.4.11 (ТК РО, Избранное, Полезное, Заметки и остальное), прошли финальную проверку и полировку.
  • «Устав ФСБ» полностью переработан: актуализированы главы о запретах, дисциплине, графике работы и структуре подразделений — добавлены СОКР, Следственное управление, Управление «Ф» и другие.
  • Автообновление стало безопаснее: файл проверяется по контрольной сумме (SHA-256) перед установкой, а при сбое замены автоматически восстанавливается предыдущая рабочая версия.

МОДУЛИ

Что внутри

Девять разделов в одном окне — от нормативной базы до заготовок макросов и личных заметок.

MOD.01Активен

Устав ФСБ

Полный текст устава фракции с быстрым поиском по разделам.

MOD.02Активен

УК РО

Уголовный кодекс сервера — статьи, сроки и санкции без переключения окон.

MOD.03Активен

ТК РО

Трудовой кодекс сервера — та же быстрая навигация и поиск по статьям.

MOD.04Активен

Общее

Миранда, порядок задержания, права задержанного, Кодекс этики.

MOD.05Активен

Избранное

Закрепляй нужные статьи звёздочкой — быстрый доступ без повторного поиска.

MOD.06Активен

Полезное

Готовые макросы — боди-камера, служебные — и справочник воинских званий.

MOD.07Активен

Заметки

Свои заметки с форматированием — сохраняются локально, только на этом ПК.

MOD.08Активен

Настройки

9 стилей текста, темы оформления, размер и прозрачность окна, автозапуск, свои горячие клавиши.

MOD.09Активен

Автообновление

Приложение само проверяет и предлагает установить новую версию.
